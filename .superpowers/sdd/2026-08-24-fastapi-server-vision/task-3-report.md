# Task 3 report: AES-GCM, S3 evidence, retention, and readiness

## Scope delivered

- Added Node-compatible AES-256-GCM evidence encryption with detached 12-byte IV and 16-byte authentication tag.
- Added asynchronous boto3 S3/MinIO storage with 3 total bounded attempts for retryable transport/408/429/5xx failures, no retries for authorization or validation errors, short connect/read timeouts, encrypted-object content type enforcement, and safe object keys.
- Added transactional MariaDB evidence metadata/audit repository and an evidence service that uploads encrypted bytes before metadata, compensates by deleting an uploaded object after metadata failure, provides scoped 60-second content tokens, safe content headers, audit events, and retention purge ordering.
- Added `/health/ready` for database, storage, and the Task 5-replaceable queue readiness protocol; failures contain availability states only.
- Added `proctoring-check-infra` and `proctoring-purge`; operational dependencies `boto3`, `cryptography`, and `jinja2` now ship in base dependencies. Imports/runtime assembly do not issue DB or S3 requests.

## Fixture provenance and compatibility

`NODE_AES_256_GCM_FIXTURE` is a literal AES-256-GCM NIST SP 800-38D known-answer vector: 32 zero-byte key, 12 zero-byte IV, 16 zero-byte plaintext, ciphertext `cea7403d4d606b6e074ec5d3baf39d18`, and tag `d0d1c8a799996bf0265b98b5d48ab919`. It is not generated by the implementation under test.

The frozen Node adapter `apps/api/src/services/evidence-encryption-service.js` uses `createCipheriv('aes-256-gcm', key, iv)` without AAD and writes ciphertext, IV, and `getAuthTag()` separately. The Python adapter preserves those three fields exactly and round-trips a Python-generated wire object in a separate test. Historical migrations `004_evidence_panel.sql` and `006_incident_evidence.sql` store `encryption_iv` and `encryption_tag` but no key-version field; the Python adapter therefore preserves the historical key-version metadata as absent (`None`) rather than inventing incompatible database metadata.
