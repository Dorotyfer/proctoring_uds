# Procedimiento para titulares de datos

1. Registrar la solicitud con identidad y fecha.
2. Verificar el alcance y responder dentro del plazo institucional.
3. Exportar únicamente los datos autorizados, excluyendo claves, descriptores y datos de otros cursos.
4. Ejecutar corrección, revocación o eliminación con doble control y auditoría.
5. Conservar la justificación de cualquier excepción de retención.
6. Informar el resultado y el canal de apelación humana.
