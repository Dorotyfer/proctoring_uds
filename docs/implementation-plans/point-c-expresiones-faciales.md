# Punto C: expresiones faciales

## Decisión

El análisis de expresiones o emociones está excluido del producto y no se implementa.

YuNet, SFace y FasNet se limitan a detección/alineación, identidad y prueba de vida. Ningún payload, tabla, evento, UI o regla debe inferir estado emocional. Gestos del desafío se representan como orientación geométrica requerida, no como emoción.

## Gate

Revisar fuentes, configuración, modelos y entregables para confirmar que no existen clasificadores, pesos, etiquetas o conclusiones de emociones. Cualquier futura propuesta requiere un proceso separado de privacidad, ética y autorización; no forma parte de este plan.
