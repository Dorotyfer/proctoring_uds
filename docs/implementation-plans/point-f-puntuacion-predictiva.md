# Punto F: puntuación predictiva

## Decisión de alcance

El release actual no implementa una puntuación predictiva de riesgo.

Las alertas existentes exponen observaciones y reglas explícitas para revisión humana; no producen una calificación opaca del estudiante. Si una versión futura incorpora agregación, deberá ejecutarse en servidor, ser explicable, versionada, auditable y solo orientativa para revisión. Nunca podrá usar emociones ni tomar una sanción automática.

## Gate futuro

Requerirá aprobación institucional, contrato de datos, evaluación de sesgo, explicación por señal, calibración medida y un mecanismo de impugnación. Ninguno de esos resultados se declara completado aquí.
